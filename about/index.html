About this website

关于本站

网站作者：呆胶布。这是影迹的介绍页，不是一款新的 Android 应用。

网站作者：呆胶布。 GitHub 账号是 CrazyGoudanli。 应用作者是卜文旭 / Eames。两件事不要并成一件。

本站做什么

按原介绍页的阅读顺序，提供目录、项目概述、功能、推荐流程、进展、界面说明和开发日志。外链指向原仓库、原发布页和原介绍页，并标明来源。

页面是静态文件，可以用任意静态网站托管，不需要数据库、付费接口或密钥。浏览器里的明暗切换只写在本机 localStorage，键名是 daijiaobu-theme。没有账号，没有统计上报，没有表单。

本站不做什么

  • 不把影迹说成呆胶布开发的应用。
  • 不补写原站留空的开发日期，不把 2026-11-06 的验收录制写成呆胶布的测试。
  • 不调用 DeepSeek、TMDB 或其他 API，也不演示「真实模型结果」。
  • 不托管 APK，不收集观影记录或密钥。
  • 不复制没有许可的原站代码和独有素材。

发布状态

源码仓库是 CrazyGoudanli/beat。GitHub Pages 地址是 crazygoudanli.github.io/beat/。从那个地址打开时，这就是正式页面。本机 127.0.0.1 只是开发预览。

构建资源前缀是 /beat/。发布用仓库里的 GitHub Actions，不另建仓库，也不启用付费服务。步骤写在 docs/deploy.md。来源与许可说明哪些内容可以随仓库分发。
